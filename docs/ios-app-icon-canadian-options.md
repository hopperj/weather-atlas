# Canadian iOS icon alternatives

Created 2026-09-07 for Weather Model Atlas in response to the request for five
more Canadian-themed options. All five were generated with the built-in
image-generation tool using the imagegen skill; no CLI fallback was used.

These are design alternatives, not changes to the active icon. The existing
`frontend/public/icons/weather-model-atlas-ios.png` and its HTML reference are
unchanged. No redeployment is needed for this design-only batch.

The original generated PNGs are preserved, fully opaque and square, without
baked-in rounded-corner masks. They are 1254 × 1254 despite the prompt's
1024 × 1024 request. Native-platform size exports can be prepared after selection.
The Canada outline in option 3 is stylized icon art, not geographic reference data.

## Final prompt set

### 1. Maple Sky

```text
Use case: logo-brand
Asset type: A single finished iOS home-screen icon for Weather Model Atlas, a Canadian weather forecasting and atmospheric-model map app.
Output: Square 1024 x 1024 PNG artwork, fully opaque, full-bleed background, square outer corners. No baked-in rounded-corner mask.
Constraints: Original independent-app identity. Clearly Canadian, with a weather-related focal mark. Strong legibility when reduced to a small home-screen icon. One icon only, not a comparison sheet. No text, initials, numbers, labels, borders, device mockups, watermarks, government wordmarks, official seals, or unrelated decorative objects.
Scene/backdrop: Warm porcelain-white background.
Subject: A single bold Canadian red maple-leaf silhouette. Cut an elegant white cloud and one sweeping airflow curve through its lower middle as negative space, leaving the maple leaf immediately recognizable.
Style/medium: Exceptionally clean, confident, flat geometric design. Very subtle embossed depth only; no glossy 3D. Canadian red and porcelain white, with no other dominant colours.
Composition: Centered large mark occupying about 70 percent of the square, generous quiet margins. It should read as both Canada and weather in one glance, not as a flag or an official agency logo.
```
