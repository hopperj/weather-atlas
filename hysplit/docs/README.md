# HYSPLIT documentation and primary papers

## Mechanics documentation

Read these in order:

1. [`manuals/HYSPLIT_5.4_User_Guide.pdf`](manuals/HYSPLIT_5.4_User_Guide.pdf) —
   current complete guide: meteorological input, trajectory and concentration
   configuration, puff/particle modes, turbulence, deposition, ensembles,
   output formats, utilities, and advanced settings.
2. [`papers/2015_Stein_NOAA_HYSPLIT_System.pdf`](papers/2015_Stein_NOAA_HYSPLIT_System.pdf) —
   best concise modern overview of model history, hybrid Lagrangian/Eulerian
   formulation, physical processes, and major applications.
3. [`manuals/1997_Draxler_Hess_HYSPLIT4_Model_Description_ARL224.pdf`](manuals/1997_Draxler_Hess_HYSPLIT4_Model_Description_ARL224.pdf) —
   foundational equations and computational mechanics.
4. [`manuals/1998_Draxler_Hess_HYSPLIT4_Overview.pdf`](manuals/1998_Draxler_Hess_HYSPLIT4_Overview.pdf) —
   trajectories, dispersion, and deposition overview.
5. [`manuals/1999_Draxler_HYSPLIT4_User_Guide_ARL230.pdf`](manuals/1999_Draxler_HYSPLIT4_User_Guide_ARL230.pdf) —
   historic command, control-file, and data-format reference.
6. [`papers/1992_Draxler_HY_SPLIT_v3_User_Guide_Model_Description.pdf`](papers/1992_Draxler_HY_SPLIT_v3_User_Guide_Model_Description.pdf) —
   original HY-SPLIT formulation and user/model description.

The live HTML guide is <https://www.ready.noaa.gov/hysplitusersguide/>.
An offline copy of NOAA's version history is
[`manuals/HYSPLIT_Updates.html`](manuals/HYSPLIT_Updates.html).

## Modern methods and applications

- [`papers/2021_Loughner_STILT_Features_HYSPLIT5.pdf`](papers/2021_Loughner_STILT_Features_HYSPLIT5.pdf) —
  time-forward/time-reversed unification and STILT-derived boundary-layer
  features in HYSPLIT 5.
- [`manuals/2015_WRF_HYSPLIT_Technical_Note.pdf`](manuals/2015_WRF_HYSPLIT_Technical_Note.pdf) —
  direct coupling to WRF, η-coordinate particle transport, parallel domain
  decomposition, and output mechanics.
- [`papers/2015_Ngan_Inline_WRF_HYSPLIT_Workshop.pdf`](papers/2015_Ngan_Inline_WRF_HYSPLIT_Workshop.pdf) —
  inline WRF–HYSPLIT design and tracer evaluation presentation.
- [`papers/2017_Chai_Volcanic_Ash_Data_Assimilation.pdf`](papers/2017_Chai_Volcanic_Ash_Data_Assimilation.pdf) —
  source inversion and satellite ash assimilation.
- [`papers/2017_Rolph_READY_System.pdf`](papers/2017_Rolph_READY_System.pdf) —
  READY's operational model and meteorological-data workflow.
